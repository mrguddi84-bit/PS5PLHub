# PS5PLHub

**Deine Payload-Websites an einem Ort.**

Ein kompakter, lokal gespeicherter Hub zum Verwalten und Öffnen von PS5-Webdiensten.

## Downloads

- [HTML herunterladen](https://github.com/mrguddi84-bit/PS5PLHub/releases/latest/download/PS5PLHub.html) und lokal im Browser öffnen.
- [Android-APK herunterladen](https://github.com/mrguddi84-bit/PS5PLHub/releases/latest/download/PS5PLHub-Android16.apk) und auf Android installieren.

## Deutsch

1. Öffne die HTML-Datei im Browser oder installiere die Android-App.
2. Trage die IP deiner PS5 ein.
3. Füge Dienste mit Namen und Port hinzu und tippe auf einen Eintrag, um die Website zu öffnen.

Die Einstellungen bleiben lokal auf deinem Gerät. Die Erreichbarkeit eines Dienstes wird nicht automatisch geprüft. Die HTML lädt keine externen Ressourcen.

## English

1. Open the HTML file in a browser or install the Android app.
2. Enter your PS5 IP address.
3. Add services by name and port, then tap an entry to open its website.

Settings stay on your device. Service availability is not checked automatically. The HTML loads no external resources.

## Español

1. Abre el archivo HTML en un navegador o instala la aplicación para Android.
2. Introduce la dirección IP de tu PS5.
3. Añade servicios con nombre y puerto; toca una entrada para abrir su sitio web.

La configuración se guarda localmente en tu dispositivo. La disponibilidad de los servicios no se comprueba automáticamente. El HTML no carga recursos externos.

## Português

1. Abre o ficheiro HTML num navegador ou instala a aplicação Android.
2. Introduz o endereço IP da tua PS5.
3. Adiciona serviços com nome e porta; toca numa entrada para abrir o respetivo site.

As definições ficam guardadas localmente no teu dispositivo. A disponibilidade dos serviços não é verificada automaticamente. O HTML não carrega recursos externos.

## Themes & languages

Ten themes: Light, Dark, Cyberpunk, Matrix, Acid Riot, Solar Storm, Ultra Violet, Candy Glitch, Inferno Ice, and BVB Black/Yellow. The interface supports German, English, Spanish, French, Italian, and Portuguese.
